
# OccidentMod — 輓歌

**繁體中文** · [简体中文](README.zh-CN.md) · [English](README.en.md)

> **讓戰鬥更有深度，讓探索重新充滿未知。**

《輓歌》（OccidentMod）是一項正在開發中的 Terraria 大型內容擴充計畫。我們希望保留原版自由探索的精神，同時重新思考職業、武器、飾品、坐騎與世界環境之間的關係。

我們追求的不只是更多裝備與 Boss，而是讓每種玩法都有值得學習的機制，讓玩家能自由嘗試搭配，並在熟悉的世界中持續發現新事物。

## 設計方向

- **職業與武器：** 探索各具特色的操作方式與戰鬥節奏，鼓勵自由搭配，而非單靠數值區分流派。
- **飾品與坐騎：** 嘗試加入主動能力，讓裝備與移動方式成為遊戲操作的一部分。
- **環境與探索：** 以新的生態、互動規則與隱藏發現，讓好奇心成為探索的理由。
- **Boss 與挑戰：** 重視可理解的攻勢、時機判斷與戰場變化，而非單純堆疊生命值。

以上皆為**開發方向**，不代表目前版本已實裝。

## 開發狀態

**目前仍處於早期開發與技術驗證階段，尚未提供完整遊戲體驗。** 現有功能可能存在錯誤、缺漏或平衡問題，並可能隨開發進度重構或移除。

Beta 0.2.1 包含閃避翻滾、職業起源頁、Poka 坐騎及高瞰者。蘑菇法杖與小蘑菇暫時移除，既有孢夢森林已移除，環境與貼圖預計重製。詳見 [更新紀錄](CHANGELOG.md)。

如果您只想關注進度，建議先收藏或關注模組。若要參與測試，請**備份存檔，並使用新角色與新世界**。

## 開發與原始碼測試

本專案使用 **C#** 與 **tModLoader**。如需從原始碼建置，請將專案放入 tModLoader 的 `ModSources/OccidentMod` 資料夾，再透過遊戲內的模組原始碼介面建置並重新載入。
