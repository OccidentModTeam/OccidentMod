
# OccidentMod — 輓歌

[繁體中文](README.md) · **简体中文** · [English](README.en.md)

> **让战斗更有深度，让探索重新充满未知。**

《輓歌》（OccidentMod）是一项正在开发中的 Terraria 大型内容扩充计划。我们希望保留原版自由探索的精神，同时重新思考职业、武器、饰品、坐骑与世界环境之间的关系。

我们追求的不只是更多装备与 Boss，而是让每种玩法都有值得学习的机制，让玩家能自由尝试搭配，并在熟悉的世界中持续发现新事物。

## 设计方向

- **职业与武器：** 探索各具特色的操作方式与战斗节奏，鼓励自由搭配，而非单靠数值区分流派。
- **饰品与坐骑：** 尝试加入主动能力，让装备与移动方式成为游戏操作的一部分。
- **环境与探索：** 以新的生态、互动规则与隐藏发现，让好奇心成为探索的理由。
- **Boss 与挑战：** 重视可理解的攻势、时机判断与战场变化，而非单纯堆叠生命值。

以上均为**开发方向**，不代表当前版本已实装。

## 开发状态

**目前仍处于早期开发与技术验证阶段，尚未提供完整游戏体验。** 现有功能可能存在错误、缺失或平衡问题，也可能随着开发进度重构或移除。

Beta 0.2.1 包含闪避翻滚、职业起源页、Poka 坐骑及高瞰者。蘑菇法杖与小蘑菇暂时移除，原有孢梦森林已移除，环境与贴图计划重制。详见 [更新日志](CHANGELOG.md)。

如果只想关注进度，建议先收藏或关注模组。如需参与测试，请**备份存档，并使用新角色与新世界**。

## 开发与源码测试

本项目使用 **C#** 与 **tModLoader**。如需从源码构建，请将项目放入 tModLoader 的 `ModSources/OccidentMod` 文件夹，再通过游戏内的模组源代码界面构建并重新加载。
